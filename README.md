🎓 Graduation Project – Medical Appointment Booking System (Flutter App)
📱 Role: Flutter Developer

📌 Project Overview
A cross-platform mobile application built with Flutter as part of the graduation project. The system facilitates clinic appointment booking for students and enables doctors to manage medical records and appointments. The app communicates with a backend API shared with a web app built using Angular.

👩‍🎓 Student Features
Browse available clinics and doctors
Book new appointments & view past bookings
Fill required survey before re-booking
View personal medical records
Receive real-time notifications (Firebase Cloud Messaging)
View booking status and receive updates.

👨‍⚕️ Doctor Features
View and manage daily appointments
Add/edit patient medical examination records
Review booking details and filter appointments
Modify or cancel appointments
Send real-time notifications to patients from within the app.

🧱 Technical Highlights
Built with Flutter & Dart
State Management: BLoC & Cubit
Clean Architecture (Presentation, Domain, Data Layers)
API Integration using Dio + Secure JWT Authentication
Push Notifications with Firebase Cloud Messaging (FCM)
Role-based UI (student / doctor)
Fully responsive RTL support (Arabic interface).
